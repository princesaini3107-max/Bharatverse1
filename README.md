# BharatVerse 🇮🇳

**AI-powered cultural tourism & local business discovery platform for India.**
Smart India Hackathon 2026 · Problem Statement **SIH26197** · Heritage & Culture.

> Explore • Experience • Preserve India's Living Heritage
> Core flow: **Discover → Learn → Interact → Preserve**

BharatVerse helps tourists and students discover Indian states, heritage sites,
food, festivals, artisans and local businesses — with an AI cultural guide, a
travel planner, a digital museum, gamified quizzes and interactive maps.

---

## ✨ Features

- **Explore India** — search + filters across states, cities, places, food, festivals, culture & artisans
- **State / City / Place** detail pages with history, significance & maps
- **Culture Hub** — articles on crafts, textiles, dance & rituals
- **Digital Museum** — browsable exhibits with detail modals
- **Artisan Stories** — maker profiles with enquiry
- **Heritage at Risk** — endangered traditions, responsibly labelled
- **Gamified Learning** — quizzes with instant feedback, score & cultural facts
- **Local Vendor Marketplace** — hotels, guides, food, crafts; sponsored listings clearly labelled
- **Vendor registration + dashboard** and an **Admin approval workflow**
- **AI Cultural Guide** — RAG-style chatbot grounded in the knowledge base
- **AI Travel Planner** — day-wise itinerary with clearly-labelled budget estimates
- **Interactive maps** — OpenStreetMap + Leaflet (free)
- **User / Vendor / Admin** roles with demo JWT auth

## 🧱 Tech Stack (all free / open-source)

| Layer     | Choice |
|-----------|--------|
| Frontend  | **Vite + React** + React Router + Tailwind CSS |
| Backend   | **Node.js + Express** (REST API) |
| Database  | **SQLite** via `better-sqlite3` (single file, no server) |
| Content   | Seed **JSON** for cultural data (read-heavy, easily extendable) |
| AI        | **RAG-ready**: keyword/TF-IDF retriever + optional local **Ollama** LLM + honest demo fallback |
| Maps      | **OpenStreetMap + Leaflet** |
| Auth      | Demo **JWT** (prototype — not production security) |

No paid APIs, no API keys, no paid hosting required.

## 🚀 Getting Started

### Prerequisites
- **Node.js 18+** (developed on Node 22)

### Install & run (one command)
```bash
npm install     # installs root, server and client dependencies
npm run dev     # seeds the DB, starts API (:5000) and Vite (:5173)
```

Then open **http://localhost:5173**.

> The Vite dev server proxies `/api` to the backend on port 5000, so you just
> use the one URL.

## 🤖 AI: demo mode vs local LLM

BharatVerse is **LLM-based by design** but never depends on a paid API.

- **Out of the box** it runs in **demo mode**: the chatbot retrieves the most
  relevant knowledge-base chunks and composes a grounded answer. Every answer
  cites its sources and never invents live prices, timings or availability.
- **To enable a real local LLM (free):** install [Ollama](https://ollama.com),
  pull a model, and configure the backend:
  ```bash
  ollama pull llama3.2
  # create server/.env (see .env.example):
  OLLAMA_URL=http://localhost:11434
  OLLAMA_MODEL=llama3.2
  ```
  Restart the server — the AI Guide will show "Local LLM connected" and answers
  will be generated by the model, still grounded in the retrieved context (RAG).

The AI status is shown live in the AI Guide page.

## 🗄️ Database Design

**Relational (SQLite)** — data that changes at runtime:
`users`, `vendor_categories`, `vendors`, `enquiries`, `quiz_results`, `travel_plans`.

**Seed JSON** — static cultural content:
`states → cities → places`, plus `food`, `festivals`, `articles`, `museum`,
`artisans`, `heritageAtRisk`, `quizzes`, and `kb` (AI knowledge base).

**Key relationships:** State→Cities→Places (1:N chain); City→Vendors; Vendor→Enquiries;
User→QuizResults / TravelPlans; articles cross-link places & artisans via `related_*` ids.

## ⚠️ Prototype notes (honesty first)

- **Demo data.** Cultural content covers Rajasthan, Punjab, Uttar Pradesh, Bihar
  and Delhi. Visiting info, prices and timings are illustrative — verify locally.
- **Images** load from Wikimedia Commons when online and fall back to generated
  heritage-toned placeholders offline, so nothing breaks.
- **Auth** is a demo JWT flow, not hardened for production.
- **Maps** show locations and simple (non-navigational) routes; they are not
  verified real-world directions.
- **Sponsored** vendor listings are always labelled; there are no fake reviews.
